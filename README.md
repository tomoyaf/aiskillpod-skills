# AI Skill Pod skill library: 166 free skills for work

166 ready-to-use [Agent Skills](https://agentskills.io) (SKILL.md) for the jobs a business team does every week: sales, marketing, operations, hiring, customer success, finance, product, legal basics, management, strategy and AI practice. Each one works in Claude (claude.ai, the desktop app, Claude Code), ChatGPT, Codex, Cursor, Gemini and GitHub Copilot.

Every skill also has its own page at [aiskillpod.com/skills](https://aiskillpod.com/skills?utm_source=github&utm_medium=readme&utm_campaign=skill-library), where you can read it, copy it, or open it in ChatGPT, Claude or Gemini without installing anything.

## Install

**Claude (claude.ai and the desktop app):** Customize > Plugins > Add > Add marketplace, enter `tomoyaf/aiskillpod-skills`, then add the jobs you want (for example `sales-skills`).

**Claude Code:**

```
/plugin install sales-skills --marketplace tomoyaf/aiskillpod-skills
```

Each job below has its own line. On Claude Code before 2.1.275, add the marketplace first: `/plugin marketplace add tomoyaf/aiskillpod-skills`, then `/plugin install sales-skills@aiskillpod-skills`.

**Codex, Cursor, Copilot and other agents** (the open `skills` CLI):

```
npx skills add tomoyaf/aiskillpod-skills
```

One skill: `npx skills add tomoyaf/aiskillpod-skills --skill account-plan`.

**By hand:** copy a folder from `skills/` into `~/.claude/skills/` (Claude Code), `~/.agents/skills/` (Codex, Copilot), `~/.cursor/skills/` (Cursor), or upload its SKILL.md in ChatGPT or Gemini.

## Give your whole team the same skills

[AI Skill Pod](https://aiskillpod.com/?utm_source=github&utm_medium=readme&utm_campaign=skill-library) puts these skills, and the ones your team writes, in everyone's Claude, Cursor and ChatGPT (Pro, Business, Enterprise) through one invite link.
